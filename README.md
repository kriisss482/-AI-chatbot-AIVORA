# 🤖 AI Chatbot

A simple and interactive AI chatbot website designed to provide users with a friendly and engaging chat experience.

## ✨ Features

* 💬 Interactive chat interface
* 🤖 AI-powered conversations
* 📱 Responsive design
* 🎨 Clean and modern UI
* ⚡ Fast and easy to use
* 🔄 Real-time message interaction

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📂 Project Structure

```text
chatbot/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start chatting with the chatbot.

## 🎯 Purpose

This project was created as a chatbot web application to practice web development and create an interactive user experience.
